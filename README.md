# 《西游原本》

> 仿欧几里得《几何原本》，用**定义、公理、公设、命题、证明、推论**重写《西游记》。
>
> *一个连如来佛祖都无法在其内部证明一致性的宇宙。*

## 这是什么？

吴承恩写了一部神魔小说，欧几里得写了一部几何教材，哥德尔证明了这类教材都会有说不清的地方。

本项目把三者硬凑在一起，回答一些早该有人严肃回答的问题：

- 一会到底是多少岁？（**命题一**：$129600 / 12 = 10800$，证毕。）
- 石猴称王合法吗？（**命题六**：依群猴之约，合法。王位靠完成约定得来，不靠血统。）
- 当了大王就能长生不老吗？（**命题七**：$F(m) \not\Rightarrow I(m)$，不能。）
- “孙悟空”这个名字是怎么来的？（**命题十**：$\operatorname{Index}(\text{悟}) = 10$，于是 $\text{孙}+\text{悟}+\text{空}=\boxed{\text{孙悟空}}$。）
- 孙悟空跳得出三界，跳得出形式系统吗？（**附录乙**：跳不出。）

## 体例

每一卷都按如下结构展开：

```
定义 → 公理与公设 → 已知事实 → 命题 → 证明 → 推论
```

并特别区分：

- **定义**：约定术语的含义；
- **公理、公设**：体系内不加证明直接采用的规则；
- **已知事实**：原文对具体人物和事件的记载，不因写进书里就成了普遍真理；
- **定理**：从以上前提能真正推出的结论。

故事里偷偷用到的前提，会尽量揪出来写明。例如：

> “我没找到神仙”不等于“这里没有神仙”。
>
> $$\neg\operatorname{FoundImmortal}(m,\text{南赡部洲},t) \;\not\Rightarrow\; \neg\exists x\,\operatorname{Immortal}(x,\text{南赡部洲})$$
